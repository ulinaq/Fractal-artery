Grow / prune / loops

Grow a tree into the tissue, extending the drawn/segmented vessels of the chosen type (else the fractal trunk). Artery and vein grow independently — pick a target and settings, grow, then try the other.

Prune: remove the outermost generations of the chosen tree — each step cuts every end branch back to its junction (the trunk to the inlet/outlet is kept). Undo with ⌘/Ctrl+Z.

Loops: join nearby branches of the chosen tree with collateral vessels (anastomoses), so a territory can be fed a second way. Test it: 📌 keep a baseline, narrow a vessel to ~0, re-run and compare.

Morphometry (Strahler)

Horton–Strahler analysis of the current tree: bifurcation, length and diameter ratios + per-order segment counts.

Adapt (structural remodelling)

Pries–Secomb: evolve the vessel radii under wall-shear remodelling toward Murray's law (|Q| ∝ r³). Replaces the tree with the adapted one; re-solve afterwards.

Compare runs (A/B)

Keep this result as a baseline, change something (a lesion, the vessels, p_in…), re-run, then compare: what changed, and Δ maps (blue = lower than the baseline, red = higher).

Batch experiment

Re-solve once per value and keep every run as a baseline.

Fit to DCE-MRI (several inputs)
Transit-time distribution

h(τ): how long blood takes to cross the tissue. Wider spread = more heterogeneous perfusion (higher CTH → less O₂ extraction).

Tracer kinetics (TKM)

Fit a tracer-kinetic model to the contrast bolus (run ▶ Tracer first) to recover plasma flow Fp / volume vp / PS / ve.

Voxel-wise maps (shown on the main canvas):

Transient (pulsatile)

Windkessel response: a pulsatile inlet, buffered by vessel compliance, gives smoother tissue flow (needs a solved result).

Multi-compartment bed

Stack N Darcy compartments (arteriole → capillary → venule) coupled by exchange β. Blood percolates down the stack; the exchange field is the capillary perfusion. Shown on the main canvas.

Uncertainty (Monte-Carlo)

Sample uncertain inputs (Latin-hypercube), re-solve N times, and report the output spread + which input drives each response.

Oxygen / solute extraction

Steady advection–reaction transport of a blood-borne solute (Krogh/Kety). Blood delivers it at the feeds; tissue consumes it at Damköhler rate k. Shown on the main canvas.
