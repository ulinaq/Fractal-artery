Parameters

Vessels

Draw in the canvas → each stroke is one segment. Share endpoints to branch (they snap).

Segments into the artery/vein selected above.

Tissue

In Tissue mode, click to outline the organ; cells outside are inactive, so the Darcy bed is organ-shaped. Multiple regions add together.

Inlets / Outlets

In Inlets/Outlets mode, click near a vessel end to set a boundary: with artery selected it becomes an inlet (▲, p_in); with vein an outlet (▼, p_out). Click a marker again to remove it. Add several for multiple inputs/outputs. You can draw separate arterial trees — each is fed at its own inlet automatically if you don't mark one. Default (none) = each tree fed at its root.

Grow

Grow the arterial tree into the tissue. Uses hand-drawn arteries as the seed if present, else the fractal trunk.
