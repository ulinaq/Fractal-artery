Vessels

Click a node or vessel to select it · drag a node to move it in the screen plane (rotate to move along depth) · Shift+click to branch from the selected node · S split · I inlet/outlet · Del delete · ⌘/Ctrl+Z undo. Drag empty space to rotate.

Compare runs (A/B)

Keep this result as a baseline, change something (a lesion, the trees…), re-run, then compare. Δ maps: blue = lower than the baseline, red = higher.

Batch experiment

Re-solve once per value — or, with a second input, once per combination (a grid) — and keep every run as a baseline.

Lesions & hotspots

Spheres in the tissue. A lesion lowers the permeability K inside it (re-run to see the perfusion deficit); a hotspot raises growth demand, so 🌱 Grow puts more vessels there. Drag a sphere's centre dot to move it (rotate the view to move it in depth).

Uncertainty & calibration

Re-solve the 3-D model many times. The trees stay fixed and one Darcy factorisation is reused unless K varies.
